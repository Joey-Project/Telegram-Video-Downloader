# Converter license notices

The FLAC converter links FLAC and Ogg statically on macOS. These verbatim
notices are installed beside the helper:

- `FLAC-LICENSE.txt` is from FLAC 1.5.0 `COPYING.Xiph`.
- `Ogg-LICENSE.txt` is from libogg 1.3.6 `COPYING`.

Both files are Xiph.Org BSD-style notices. The versions above identify the
upstream license sources inspected for this packaging change.
